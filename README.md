# luci-app-mclash

A Mihomo manager for OpenWrt with TUN/TProxy capture, subscriptions, nodes, proxy chains, rules, DNS management and Zashboard.

- Independent subscription updates and core updates.
- Browser/router latency tests and service logs.
- Built-in GeoIP and GeoSite databases.
- English UI with an optional Simplified Chinese package.

## Install

Current release: **v2.0.0** (`2.0.0-r1`).

Download the APK or IPK matching your firmware from [Releases](https://github.com/liuyi-htu/luci-app-mclash/releases/latest). Install `luci-i18n-mclash-zh-cn` for Chinese translations. Mihomo is installed separately through the plugin.
